🚀 你的 15 分钟部署路线

👉 详细步骤见 DEPLOY.md，每步都写了截图说明
在 GitHub + Supabase + Vercel 三个网站注册免费账号
在 Supabase 创建项目 → SQL Editor 跑 schema.sql → 复制 2 个 API 密钥
在 GitHub 创建新仓库 → 把项目所有文件上传
在 Vercel 点 "Import Project" → 选择仓库 → 添加 4 个环境变量 → Deploy
部署完成后打开网址 → 输入你设置的密码登录
在 iPhone Safari 打开 → 分享 → 添加到主屏幕（变成紫色日历图标）

  • 能正常进入应用（说明登录、数据库、Vercel 都没问题）

  • 在「SOP」模块创建一个「晨间流程」模板

🔒 安全性

措施说明
单密码保护登录页只接受 APP_LOGIN_PASSWORD
JWT 签名所有 API 通过 HMAC-SHA256 签名验证
HttpOnly CookieToken 存在 HttpOnly cookie 防 XSS
中间件守卫所有非登录路径强制鉴权
HTTPSVercel 自动证书，全站加密
单一账户RLS + 密码模式 = 只你一人

数据存储在 Supabase 全球分布式 PostgreSQL，可用性 99.9%。

🆘 常见问题

Q：忘了密码怎么办？

登录 Vercel → 项目 → Settings → Environment Variables → 改 APP_LOGIN_PASSWORD → 重部署

Q：能在 Windows 上部署吗？

可以。整个流程都在浏览器里，与操作系统无关。

Q：OCR 准确率？

Tesseract.js 对清晰截图 85-95%。模糊手写体可能略低。

Q：能换 ChatGPT 直连吗？

当前 OCR 方案完全免费。如要 ChatGPT API 直接对话，需要每月约 $5 费用，可以以后扩展。
